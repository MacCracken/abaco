# Abaco — Forward Roadmap

> Forward plan only. Completed-work history lives in [`../../ROADMAP.md`](../../ROADMAP.md);
> per-tag chronology in [`../../CHANGELOG.md`](../../CHANGELOG.md); live state in
> [`state.md`](state.md).

Abaco is post-1.0, so it follows standard SemVer. The **2.2.x arc** is a
modernization tail that brings abaco fully in line with the patra/sigil
first-party reference shape on the Cyrius 6.0.x toolchain. No public API
changes are expected across the arc — it's infrastructure, hardening, and
docs. The minor (2.3.0) opens once the arc closes.
